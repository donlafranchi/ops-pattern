Decision matrix · Build-agent prompt additions

Four moves to shrink the 30-minute read

Ranked by leverage. Not mutually exclusive — additive. The matrix shows where each move pays back.

Move

01 · Highest leverage
Triage upstream
Agent classifies every choice before surfacing it.
Setup effort Low ~20 lines added to agent's system prompt — three buckets and a default.
Decision-events eliminated Most Many "options" turn out to be implementation choices the agent can make from the ticket.
Risk if agent gets it wrong Medium Agent commits to a path you'd have steered differently. Mitigated by post-hoc visibility — agent logs what it decided.
02
Constraint-first elicitation
One question before options, not three options after.
Setup effort Low Rule: "If a decision turns on a constraint only Don knows, ask the constraint. Then pick."
Decision-events eliminated Many Replaces 30-minute trade-off reads with 60-second constraint answers.
Risk if agent gets it wrong Low Worst case: agent asks for a constraint that doesn't matter. Cheap to correct.
03 · Best ratio
Standing defaults registry
A short doc the agent reads on every turn.
Setup effort Medium Document grows over time. Each recurring decision becomes a one-line default.
Decision-events eliminated Many, compounding Every default you write eliminates a class of future decisions, not just one instance.
Risk if agent gets it wrong Low Defaults are explicit and visible. Agent cites them when applying. Easy to override or revise.
04 · Cheapest
Compression contract
Hard word budget. Analogy-first technical content.
Setup effort Low Lift the BLUF/Minto section from your Claude userPreferences. Paste into agent prompt.
Decision-events eliminated Few Doesn't remove decisions — only shortens the read on the ones that remain.
Risk if agent gets it wrong Low Detail compressed too aggressively; you ask for more. Reversible per turn.
Read this matrix as: Triage upstream removes the most decisions but carries the most risk if the agent misjudges what's yours. Defaults registry has the best leverage-to-effort ratio over time. Compression alone won't move the needle — it narrows the reads you still have to do, but you're still doing them.
