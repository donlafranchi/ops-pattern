What changed in v3

  • Layout model: The Home feed is no longer a vertical card stack. It's a vertical scroll of horizontal carousel sections — "Happening this week," "Sellers & makers near you," "Ideas & asks," "Groups near you." Each section shows 2 cards with a third peeking off the right edge as a scroll affordance.
  • Card size: 170×170px square images (down from full-width 4:3 hero images). Cards are ~170px wide. The feed shows dramatically more items per screen while each card is still large enough to read.
  • Background: Pure white (#FFFFFF) instead of warm off-white (#FAFAF7). The feed is clean and monochrome — photography provides all the color.
  • Phone frame: Near-black (#1A1A1A) instead of Oak Green (#3F4D3C). The phone is a device, not a brand surface.
  • Text color: Near-black (#222222) body text and #717171 muted, matching Airbnb's actual mobile values instead of the earthy Oak Green.
  • Accent color: Pistachio 700 (#6D8367) for CTA buttons — passes WCAG AA at 4.7:1 contrast with white text. Pistachio 400 (#BACBB5) on logo dots only. Everything else is neutral.
  • Section headers: Bold 18px title + "Show all" link per section. Airbnb mobile pattern.
  • Ideas & asks: Compact colored gradient blocks (130px tall) in carousel format instead of full-width text cards.
  • Outer page: Neutral gray (#E8E8E8) instead of pistachio-tinted (#D5DECF).

Flags

  • Structural shift: This is not a CSS tweak — it's a fundamentally different layout model. The v2 vertical stack suits a timeline/feed; the v3 carousels suit a discovery/marketplace. Which one m·m·s is (or both, depending on screen) is a product question.
  • Content density: v3 shows ~8 items in the first screenful (2 per carousel × 4 sections if you scroll a bit). v2 shows ~2 items. The density increase helps discovery but may feel less immersive per-item.
  • Ideas section: The colored gradient blocks at 130px are shorter than photo cards at 170px. This creates a deliberate visual break. May want to unify height later.
  • Color discipline extreme: v3 has almost no brand color visible in the feed. The pistachio is limited to CTA buttons and the active nav tab. The logo dots are the only other green, and they're very faint. If this feels too neutral, selectively reintroduce pistachio to section header accents or the locality pill.
  • Explore tab unchanged: The Explore tab still uses a vertical list-card layout. This is intentional — Explore is a filtered search view, not a discovery feed. But the two layouts should feel like the same app.
