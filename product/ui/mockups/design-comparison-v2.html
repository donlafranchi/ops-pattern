Gap Analysis v2: Main Street Simplified vs Airbnb

The simplified palette eliminates most gaps from v1. Main Street now shares Airbnb's structural DNA: white canvas, dark neutral text, clean photo cards, and a single accent color used sparingly. Here's what remains.

Dimension Airbnb Main Street v2 Verdict
Background Pure white (#FFFFFF). Pure white (#FFFFFF). Match
Text color #222222 body + headings. #2D2D2D body + headings. Fractionally lighter — imperceptible difference. Match
Secondary text #717171. #717171. Identical. Match
Border color #EBEBEB. #EBEBEB. Identical. Match
Card title weight 15px / 600 (SemiBold). 15px / 600 (SemiBold). Was 16px/500 in v1 — now matches. Match
Photo card overlays Heart icon only. Optional "Guest favorite" white pill (sparingly). No color badges. Heart icon only. No tier badges, no kind pills. Tier info moved to text zone below ("Product · Independent"). Clean. Match
Accent color frequency Rausch Red: active nav icon + accent lines on text-forward cards. ~3 instances in the feed. Satin Pistachio: active nav icon + accent lines on text-forward cards. ~4 instances (3 text-forward cards + 1 nav). Nearly identical restraint. Match
Text-forward cards Light gray bg (#f7f7f7), accent line, uppercase category, large title, meta. Light gray bg (#F7F7F7), pistachio accent line, uppercase category, large title, meta. Same structure, pistachio line instead of red. No emoji circles, no tinted badges. Match
Search bar White pill, shadow, filter icon on right. White pill, shadow, filter icon on right. Now includes the filter affordance (was missing in v1). Match
Filter pills Border + white bg. Active: dark fill, white text. Below search, hairline separator. Identical treatment. Active uses #2D2D2D fill (vs Airbnb's #222). Hairline below. Match
Active nav state Rausch Red (#FF385C) — high-contrast pop on white. Pistachio (#A0B49A) — lower contrast than red on white. The pistachio reads more muted than Rausch. Functionally clear but less assertive. Close — inherent to hue
Social proof Star + numeric rating on every card. No ratings (intentional — per principles.md). Ownership tier in text below card instead. Different trust signal. Intentional trade-off
Information density Title, subtitle, detail, price. No kind label. Title, subtitle, kind + tier label, price. Extra kind line because we serve multiple content types. Airbnb doesn't need this — they show only one type per tab. Intentional — multi-type feed
Card spacing 20px horizontal. 20px horizontal. Matched (was 24px in v1). Match

Summary

10 of 14 dimensions are now a direct match. The three "close" verdicts are all intentional trade-offs (pistachio is inherently lower-contrast than red; no ratings is a platform value; multi-type feed needs kind labels). None are execution gaps.

The v1 comparison had 4 actionable gaps and 6 close calls. v2 has 0 gaps and 3 close calls — all structural, not fixable by CSS alone because they reflect deliberate product differences.

What Changed from v1

Canvas: Warm off-white (#FAFAF7) → pure white (#FFFFFF). Eliminated the warm-cool contrast issue.

Text: Oak Green (#3F4D3C) → dark neutral (#2D2D2D). Text is now invisible as a design element — it reads, it doesn't brand.

Card titles: 16px/500 → 15px/600. Matches Airbnb's weight and size. Scans faster.

Accent frequency: 8+ pistachio instances → 4. Killed tier badges on photos, killed tinted kind badges, killed decorative emoji circles. Pistachio now appears only on accent lines and active nav — same placement as Rausch.

Photo overlays: Removed entirely. Photos are clean. Ownership info dropped to text zone as "Product · Independent" in muted gray.

Text-forward cards: Dropped the pistachio-tinted kind badge and emoji circle. Replaced with Airbnb's editorial approach: uppercase category label in muted gray + thin accent line.

Search bar: Added the filter icon affordance (borrowed from Airbnb).

Bottom nav: Active state now uses pistachio instead of dark green. Lower contrast than Rausch but identifiable.
