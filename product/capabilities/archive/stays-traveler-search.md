# Capability: Traveler Search & Browse

**Description:** Travelers find rentals by location and dates, with total cost and amenities visible on every result — no clicking required to understand what they'll pay.

**Bundles:** b1

**User Story:**
As a traveler, I want to search for a rental by location and dates and immediately see total costs, top amenities, and cancellation policies, so I can make a decision without playing detective.

**Scope:**
- Location search (city, neighborhood, address)
- Date picker (check-in / check-out)
- Map view with rental pins
- Result cards showing: photo, total cost for stay, top 3 amenities, cancellation policy, Local Host badge, guest capacity
- Filters: property type, guest count, amenities, Local Host only, price range
- Default sort: amenity relevance (not lowest price)
- Alternative sorts: distance, newest listings, highest-rated (T2)

**Out of Scope:**
- Saved searches / alerts (T2)
- "Similar listings" recommendations (T2)

**Related Capabilities:**
- Total Cost Display
- Amenity Showcase
- Mandatory Disclosures
