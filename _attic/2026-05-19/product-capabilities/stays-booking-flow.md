# Capability: Booking Flow

**Description:** Travelers request a booking with full cost visibility. New hosts must exchange messages before confirming; established hosts can enable instant book.

**Bundles:** b1

**User Story:**
As a traveler, I want to book a rental knowing exactly what I'll pay and what to expect, with a real conversation with the host if they're new.

**Scope:**
- Request-to-book with message to host
- New hosts (first 3 bookings): mandatory message exchange before confirmation
- Established hosts: option to enable instant book
- Payment summary: total cost, tax breakdown, cancellation terms — all on one screen
- No surprise fees at checkout
- Confirmation includes: check-in instructions, house rules, host contact info, neighborhood tips
- Cancellation flow matches the policy shown at search time

**Out of Scope:**
- Split payments / group booking (T3)
- Insurance integration (T3)
- Dispute resolution (T3)

**Related Capabilities:**
- Total Cost Display
- Host Onboarding
- Mandatory Disclosures
